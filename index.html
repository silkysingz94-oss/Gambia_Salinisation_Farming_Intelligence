06. Methodological notes
BGS SEC represents electrical conductivity information. A pixel code of zero with a blank Raster.SEC attribute is not sufficient evidence of zero conductivity or freshwater.
Groundwater pixel codes should not automatically be interpreted as measurements in metres below ground level. Preserve the returned raster attributes and verify their meaning against the BGS layer documentation.
ESA WorldCover identifies land-cover classes. Cropland is not equivalent to agricultural suitability or crop productivity.
This dashboard provides map visualisation, point identification, response diagnostics and sample exports. It does not calculate a validated groundwater–agriculture suitability index.
