06. Methodological notes
BGS SEC is a groundwater electrical-conductivity indicator, not a directly mapped fresh–saltwater interface.
ESA WorldCover identifies land-cover classes. Cropland is not equivalent to agricultural suitability or crop productivity.
This dashboard provides map visualisation, point identification and sample export. It does not calculate a validated pixel-level groundwater–agriculture suitability overlay.
